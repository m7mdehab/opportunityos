# Founder Web Alpha deployment

The durable zero-dollar preview target is Render: one Docker web service and one
managed PostgreSQL database described by `render.yaml`. The container migrates
the database before starting Next.js on Render's public port and FastAPI on
loopback. Browser API calls remain same-origin through the Next.js rewrite.

## One-time deployment

1. In Render, create a Blueprint from this public GitHub repository.
2. Select `main` and the repository-root `render.yaml`.
3. Enter a strong value for `OPPORTUNITYOS_FOUNDER_PASSWORD` when prompted.
4. Add the validated Founder Truth Pack to the web service as a Render Secret
   File named `truth_pack.yaml`. Render mounts it at
   `/etc/secrets/truth_pack.yaml`; the Blueprint configures
   `OPPORTUNITYOS_TRUTH_PACK_PATH` to that exact runtime-only path.
5. Apply the Blueprint and open the assigned `https://*.onrender.com` URL.

The session secret is generated by Render and never enters Git. Public-proxy
deployments force `Secure`, `HttpOnly`, `SameSite=Lax` session cookies. The API
still refuses to boot without PostgreSQL and both secrets. API documentation is
disabled, and every application route other than the authentication boundary
requires a signed founder session.

The repository and Docker image must never contain the Founder Truth Pack, CV,
credentials, or database dumps. The Truth Pack is supplied only through the
provider Secret File above, and production data lives in the external persistent
PostgreSQL service. A Cloudflare Quick Tunnel is testing evidence only and is not
a durable or canonical Founder Alpha deployment. Render's free PostgreSQL
database expires after 30 days, so export or replace it before expiry if the
alpha is retained.
