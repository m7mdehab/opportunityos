# FR-007 W1: current-runtime compatibility matrix

This matrix is from current code consumers, not an assertion that W0 cloud capabilities are implemented. `scripts.cloud_runtime_bridge.plan_runtime_environment(role, source)` validates the role's W0 required names and returns only safe current aliases plus named blockers. `build_runtime_environment` refuses all currently blocked roles. A later deployment entrypoint must call it before launching a child process; merely importing this module changes no environment. Never pass a raw cloud environment directly to current application startup and mistake W0 preflight for integration.

Other actual legacy controls: `OPPORTUNITYOS_TRUTH_PACK_PATH` is an optional API path and worker handlers can default to a private local truth-pack file; no safe cloud truth-state mapping exists. The bridge rejects a supplied local path and blocks API/worker readiness even without one. `NEXT_PUBLIC_USE_MOCK_API=1` enables MSW in the browser and is rejected. `OPPORTUNITYOS_API_PORT` only chooses a localhost rewrite and is not a cloud API URL. `OPPORTUNITYOS_HIGH_FIT_THRESHOLD`, `OPPORTUNITYOS_FORCE_SECURE_COOKIES`, and scheduler `OPPORTUNITYOS_POLL_INTERVAL_HOURS` are existing behavioral controls, not substitutes for cloud credentials; the bridge does not copy or reinterpret them. `scripts/production_start.py` still combines migrations, API, worker/scheduler, and web; it is not a role-scoped cloud entrypoint. The local alpha runner reads a separate local configuration file and is excluded.

Collision rule: `CLOUD_DATABASE_URL` is authoritative for cloud roles. If `OPPORTUNITYOS_DB_URL` is also supplied, it must be byte-for-byte identical or planning fails before any environment is built. No fallback to legacy-only DB, SQLite, localhost, mock mode, local truth file, or founder-password/session credentials is allowed. Diagnostics include names only. The only emitted alias is server-side `OPPORTUNITYOS_DB_URL`; no privileged value is ever emitted as `NEXT_PUBLIC_*`. After cloud cutover, the local founder password/session secret, local truth-pack path, local API port rewrite and mock switch must be retired from production, not automatically inferred from neutral config. Local development/test use remains distinct.
