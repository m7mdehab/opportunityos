- Source policy remains authoritative; force does not bypass read policy or
  active cooldown.

3. POLL NOW / A-7 IMPLEMENTATION
--------------------------------------------------------------------------------
POST /api/worker/poll-now:
- returns after durable enqueue and never waits for source acquisition,
  normalization, evaluation, or projection publication;
- generic Poll Now is due-only and never blind all-source enqueue;
- explicit source requests obey source policy, cooldown, and active-job
  deduplication; force may override only the not-due condition;
- current persisted feed remains independently readable while poll work is
  pending.

The PostgreSQL acceptance fixture deliberately gives every other read-allowed
production-registry source a future next_due_at and asserts the generic request
enqueues exactly one known due source. This prevents a false-green test where
unrelated never-polled sources could silently warm up.

4. ASYNC PROJECTION MAINTENANCE
--------------------------------------------------------------------------------
Founder filter/facet/unhide mutations no longer synchronously refresh the
feed_projection corpus.

The authoritative settings mutation and truth-pack-scoped
refresh_feed_projections job insertion are committed atomically.

Worker maintenance:
- loads the authoritative Truth Pack;
- requires the queued truth_pack_hash to match;
- refreshes only existing projections for that truth_pack_hash;
- leaves historical/synthetic projection hashes untouched;
- is retryable through the durable worker queue;
- permits GET /api/opportunities to continue serving the previous persisted
  projection until publication completes.

Important scope note:
Some settings routes still calculate response metadata such as affected_count.
This wave removes synchronous bulk projection publication from the request
path; it does not claim every settings endpoint performs zero opportunity-row
inspection.
