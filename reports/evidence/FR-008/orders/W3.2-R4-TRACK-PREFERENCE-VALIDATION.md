# W3.2-R4 — Track preference value validation

## Finding

Review of the green R3 candidate found that the legacy `preference.track` predicate represents the employment-versus-independent track choice, but the generic exact-value comparator would also accept unrelated values (for example, `remote`) as a preference mismatch. Such values are outside this predicate's meaning and must remain unscored.

## Remediation

Allow only recognized employment/independent values for `preference.track` before comparison; normalize the `procurement` job-track spelling to the independent category if encountered. Add a synthetic test proving an unrelated work-mode value on this predicate does not create a preference dimension or score. Do not alter other preference fields or objective scoring.
