# W1.1 — Canonical employment profile scoring contract

## Deliverable

Add a privacy-safe integration test proving the repository-managed, hash-verified canonical Truth Pack projects dated employment and responsibility evidence into the matching scorer. The test must never print assertion values, titles, organizations, dates, raw CV text, or profile content. It must assert that a scored employment opportunity does not report “No verified employment record” or “No verified responsibility/experience records”, and that the affected dimensions retain evidence references. Keep the existing synthetic timeline behavior unchanged.

## Acceptance commands

1. `python -m unittest matching.test_fr008_profile_contract -v`
   - Expected: exit 0; the canonical pack hash verifies; scorer seniority/experience and responsibility dimensions both contain evidence refs and neither emits the missing-history unknown.
   - Evidence: `reports/evidence/FR-008/orders/W1.1-PROFILE-test.txt`
2. `python -m unittest matching.test_seniority -v`
   - Expected: exit 0; existing overlap, missing-date, internship, family-tenure, and leadership timeline regressions remain green.
   - Evidence: `reports/evidence/FR-008/orders/W1.1-TIMELINE-test.txt`
3. `python scripts/check_repository.py`
   - Expected: exit 0 with `Repository integrity checks passed.`
   - Evidence: `reports/evidence/FR-008/orders/W1.1-repository.txt`

## Allowed files

- `matching/test_fr008_profile_contract.py` (new)
- `reports/evidence/FR-008/orders/W1.1-*.txt` (raw acceptance output only)

## Frozen files

All other files, including the canonical Truth Pack, scorer implementation, fixtures, mirrors, and migration/schema state. Do not access repository `private/` or any external desktop CV/profile files. The integration test must not log or include actual profile data in assertions/error messages/evidence; only pass/fail and aggregate unittest output are allowed.
