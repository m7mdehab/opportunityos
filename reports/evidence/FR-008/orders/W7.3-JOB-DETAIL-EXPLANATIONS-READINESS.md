# W7.3 readiness — Job-detail explanations

**Decision:** `READY / ORDER-LOCKED`

W7.2 is integrated and its report/evidence are pushed at `5c80fcb`. The brief's scoring contract requires qualification, Capability Fit, Preference, and Confidence to remain separate and says the Recommended composite cannot be the only explanation shown to the Founder.

The current detail API already returns preference and confidence scores/factors, the fit dimension breakdown, strengths/gaps/unknowns, qualification constraints, and a plain explanation. The drawer already shows constraints, fit dimensions, strengths/gaps/unknowns, and geography reasoning. The web `Scoring` type and synthetic detail mock do not yet carry preference/confidence fields, so the UI cannot display all existing API explanation layers consistently. This slice can close that gap additively without changing API or scorer behavior.

The implementation is limited to typed detail payload parity and a read-only explanation presentation in the drawer, with synthetic browser coverage for populated and unavailable detail. Use no private Founder profile or truth-pack data. No schema, database, or deployment is required; the hosted review surface remains unavailable under the existing local-only boundaries.
