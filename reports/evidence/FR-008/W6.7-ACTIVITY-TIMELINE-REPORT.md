## Delivered

- Added authenticated `GET /api/opportunities/{id}/tracker-events`, reusing the indexed W4.1 append-only event table. Pages are bounded to 100 and ordered newest-first by event timestamp and ID.
- The SQL projection selects event ID, action type, from/to states, and event time only. It excludes `metadata_json` and idempotency keys; no event records or current tracker state are changed.
- Added a detail-drawer timeline with safe labels, UTC-aware display, loading/empty/error states, and bounded “Load older activity” pagination. Unknown event types display a generic label. Event IDs and metadata are not rendered.
- The timeline refreshes in an open drawer after tracker-state changes and note, follow-up, interview, and document mutations. The existing synthetic tracker-event store backs the mock endpoint, with the same field projection; feed and Tracker summary rows remain unchanged.
- The hosted adapter returns a static 501 for the timeline route before hosted config, CSRF, auth, or provider work.
