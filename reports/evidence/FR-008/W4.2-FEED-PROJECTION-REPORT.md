## What changed

The projection model and additive migration `0016_fr008_projection_fields` add nullable title level, target tier, preference score, and confidence score columns. Newly built projection rows normalize family and level from the posting title, resolve target tier only from verified role and same-subject tier evidence, and persist preference/confidence separately from capability fit and Recommended priority. The projection version is now `v2`.

`outside_targets` is emitted only for a recognized title family when the supplied TruthGraph contains verified positive target roles but none normalize to that family. Unknown title families, no target-role evidence, missing tiers, and conflicting tiers remain `NULL`. Preference and confidence are stored only when finite numeric values fall in the inclusive 0–100 range. The same validated values feed the existing priority calculation; W3.4 ordering and weights are unchanged.

The migration is additive and reversible. Existing projection rows are not rewritten, so their new columns stay `NULL` until a later refresh. This slice adds no feed API filters or Founder UI behavior.
