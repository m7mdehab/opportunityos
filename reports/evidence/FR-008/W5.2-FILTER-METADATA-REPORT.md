## Contract

The endpoint reads only grouped values and scalar aggregates from visible `feed_projection` rows for one truth-pack hash. Counts are independent of other selected feed filters and include tracked and ineligible projections. The response states this scope explicitly.

It reports counts for track, qualification decision, work mode, country, city, remote scope, employment type, seniority, target tier, title family, and source ID. Null/blank values are represented as `unknown`; title family `other` is grouped into `unknown`. Each facet is sorted by count descending and value ascending. The response includes total distinct option count and caps returned options at 100 with an explicit `truncated` flag.

Fit, preference, confidence, and priority scores each include min/max, unknown count, and inclusive 90+, 80+, 70+, 60+, and 50+ counts. Posted date includes min/max and unknown count. The endpoint returns the six supported W5.1 sort keys and stable IDs/reasons for unsupported FR-008 §7 filter families.

While aligning the counts with filter behavior, W5.2 made the W5.1 unknown selection consistently include normalized `unspecified`, blank, and literal `unknown` values where applicable. It also normalizes persisted categorical whitespace in SQL. A first regression run exposed a stale SQL-string assertion; only its predicate-text expectations were refreshed, and the full focused suite then passed.
