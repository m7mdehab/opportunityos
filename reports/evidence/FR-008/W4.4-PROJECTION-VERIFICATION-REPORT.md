## Change

Added `verify_feed_projection_page` in `storage/feed_projection_invariants.py`. It scans one truth-pack-scoped page with an exclusive projection-ID cursor, a 100-row maximum, and a one-row look-ahead. It compares projection identity and opportunity copies, current evaluation decision/fit/time, W4.2 title family/level, bounded preference/confidence scores, and recognized target tiers. If given a TruthGraph, it also checks the target tier against same-subject verified role/tier resolution. Legacy v1 null W4.2 fields remain accepted.

The query selects scalar columns only. Preference and confidence are extracted as individual JSON scalars in SQLite/PostgreSQL; the verifier does not load the full evaluation-detail/rationale JSON, descriptions, raw payloads, reasons, or `search_text`. Results provide aggregate issue counts, bounded one-way issue tokens, and a cursor fingerprint through safe serialization. No rows are repaired or written.
