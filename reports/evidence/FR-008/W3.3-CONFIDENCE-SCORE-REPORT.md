# W3.3 — Confidence score

**Status:** `PARTIAL / REVIEWABLE / NOT YET FOUNDER-TESTABLE`

## Result

Added `confidence_score` (0–100) and seven named, API-visible confidence factors. The score answers whether evidence is complete and reliable; it remains separate from capability fit, preference fit, and qualification. Unknown evidence remains unknown. It lowers evidence confidence but does not become a capability penalty or an assumed negative constraint result.

The scalar is the arithmetic mean of the seven factor scores, rounded to two decimal places. All thresholds are deterministic interim heuristics and have not been tuned against Founder-reviewed labels.

| Factor | Interim rule |
| --- | --- |
| `description_completeness` | Description length bands: under 80, 80–249, 250–599, 600–1199, and 1200+ characters. |
| `location_remote_scope_clarity` | Structured work mode, remote scope/regions, and location determine clarity; missing remote scope or physical location lowers the factor. |
| `experience_requirement_clarity` | Numeric years threshold scores 95; unquantified experience language 40; seniority without years 75; neither stated 50. |
| `required_skill_extraction_reliability` | Structured skills 95; extracted skills from requirements 70; description-only extraction 55; none 25. |
| `compensation_completeness` | Amount, currency, and interval 100; partial details 50; absent 25. |
| `source_freshness_and_strength` | Fetch-age bands at 7/30/90/180 days are averaged with a five-signal provenance completeness score (source id, URL, feed, pointer, checksum). |
| `founder_evidence_completeness` | Relevant capability dimensions score 35 for unknown/no evidence reference, 65 for unknown/partial reference, 95 for referenced/no unknown, and 55 for unreferenced/no unknown; averaged across relevant dimensions. |

The previous uncertainty subtraction from capability fit has been removed. The legacy `uncertainty_penalty` remains persisted as a diagnostic, while the old policy field is retained for compatibility and no longer adjusts fit. Qualification and the preference score are unchanged. W3.3 also fixed an existing scorer exception when a posting has no comparable seniority title; its explanation now reports `unknown` without inventing a level.

## Persistence and API

No migration was needed. `confidence_score` and `confidence_factors` are written into the existing nullable evaluation-detail JSON and exposed on the opportunity detail API. Historical rows with no detail return `confidence_score: null` and an empty factor list. A portable API test covers both the new payload and the historical fallback without opening a database connection.
