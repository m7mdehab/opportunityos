# W4.1 — Founder tracker schema foundation

**Status:** `PARTIAL / REVIEWABLE / SCHEMA ONLY`

## Implemented

Added additive migration `0015_fr008_tracker_foundation` and matching ORM models. The migration adds nullable `saved_at`, `applied_at`, and `closed_at` fields to the existing triage row without changing old values or inferring timestamps. It adds an append-only activity event table with unique optional idempotency keys, plus normalized application details, private notes, follow-ups, interview records, document links, and compact tracker snapshot metadata.

Snapshot metadata stores a small title/location/source/score/version record and references an `artifact_cache` cold object for content. It does not add descriptions or CV content to a new hot table. The tracked metadata uses restrictive opportunity/artifact foreign keys to preserve referenced records. PostgreSQL migration SQL enables RLS and revokes browser access for new private tables; an activity trigger blocks event updates/deletes. The existing `dismissed`/`snoozed` values remain valid; no transition API or state check constraint was added.
