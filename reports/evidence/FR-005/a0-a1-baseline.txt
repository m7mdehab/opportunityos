--- The two skips, named ---
Both are the same test, one entry per docstring line:
  scripts.test_alpha.TestProcessLifecycleHelpers.test_is_zombie_detects_an_unreaped_exited_child
  skipped: 'zombie process state is POSIX-specific; Windows has no equivalent'

This is a genuine platform inapplicability, not a masked failure. A-1's expected result says
"0 skipped"; that is a CI (Linux) property and cannot hold on the Master's Windows host. The
row is therefore evidenced in two halves -- the Windows count with the skip named here, and
the CI count from the workflow run. The expected result is NOT rewritten; see the report.
