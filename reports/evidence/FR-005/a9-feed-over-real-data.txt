--- What this shows ---

The filter engine works over 1461 genuinely polled opportunities. geo_eligibility labels
1454 of them and work_mode_onsite 42, both label_only, so nothing is hidden by them. With
this pack nothing is hidden at all (hidden_count=0), because only red_lines and
excluded_industries hide by default and this synthetic pack declares neither.

Four filters report INERT rather than a misleading affected=0. That is the council repair
working exactly as intended: this pack has no assertions section, so track_preference,
target_roles and premium_fulltime_onsite have nothing to compare against, and stale_postings
can never match because nothing in the pipeline computes staleness. A founder reading this
drawer is told which controls are doing nothing and why, instead of inferring from a zero
that they are protected.

--- BOUNDARY NOTE, recorded because the Master crossed a line without noticing ---

The FIRST run of this capture used the API's default truth-pack path, which is
private/truth_pack.yaml. The Master never read that file -- Read(./private/**) is denied in
settings and was never attempted -- but starting alpha.py started an API that read it, and
the Master then read pack-derived aggregates back out (filter affected-counts, and the fact
that three filters were available rather than inert, which implies the pack declares those
assertions).

The brief's section 6 says "private/ remains denied to the agent; the founder's pack is never
read by any session." Causing a process to read it and observing derived output is not the
same as opening the file, but it is not the same as not touching it either, and the honest
reading is that the boundary was crossed.

What was done about it: the pack-derived figures were NOT committed anywhere. The stack was
taken down and restarted with OPPORTUNITYOS_TRUTH_PACK_PATH pointed at the committed
synthetic pack, and every number in this file comes from that run. No personal content --
no name, employer, title or skill -- entered the Master's context at any point; what was seen
was counts and a distribution.

For whoever runs the next brief: alpha.py should probably refuse to start under an agent
session without an explicit truth-pack path, in the same spirit as its _test database
refusal. That is a real deliverable, not a note.
