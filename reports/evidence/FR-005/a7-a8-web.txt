--- A-7: lint ---
$ npm run lint          # eslint . --max-warnings=0
EXIT=0

This did not pass first time, and the reason is worth recording. On the Master's first run it
reported 514 errors and 5548 warnings across 14 files -- every one of them inside Playwright's
own bundled HTML-report viewer (codeMirrorModule, defaultSettingsView, sw.bundle.js, ...).
The three generated report directories are gitignored, but ESLint keeps its own ignore list,
so `npm run lint` was order-dependent: clean on a fresh checkout, and thousands of problems
once anyone had run `npx playwright test`. CI lints before it runs Playwright, which is the
only reason it never saw this. Fixed by ignoring playwright-report/, playwright-report-real/
and test-results/ explicitly. Lint now exits 0 regardless of run order.

--- A second latent defect found while doing this ---
`screenshots.spec.ts` wrote its PNGs into reports/evidence/FR-004/, so every full Playwright
run silently rewrote a closed brief's committed evidence. The D3-web implementer hit it and
worked around it by running `git checkout -- reports/evidence/FR-004/...` after each run.
Evidence for a brief that has already passed its gate must not be mutable by a later brief's
test run, so it now writes into the active brief's directory. Verified after the fix:

$ git diff --stat reports/evidence/FR-004/
(empty -- FR-004's evidence is untouched by this brief's test runs)
