# OpportunityOS Session Commands

These are launch commands only. Mutable OPOS state belongs in canonical repository files, not here.

## RESUME

`Resume OPOS from canonical state.`

The Owner/Overseer verifies current control-plane and OPOS repository state, recovers the active brief/open work/unresolved evidence, loads only task-relevant deeper sources, and continues without asking the Founder to restate retrievable history.

## COMPACT

`Compact and close this session to canonical state.`

Reconcile durable decisions, architecture/roadmap when changed, generated state, active brief/task, reports/evidence, and `docs/CHAT_RESUME.md` last. Run context-integrity plus applicable repository checks. Do not create a giant handoff.

## MASTER

`Execute the current active brief as Master. Start from AGENTS.md.`

The Master performs a capability preflight, uses the least expensive capable workers actually available, integrates evidence, repairs failed gates, and returns the standard Master report. The Master never self-authorizes final closure.
